# Warrior Assets

Generated by `odin/tools/warrior/build.sh` (Blender headless).

- `warrior_blue.glb` — blue-team skinned melee warrior.
- `warrior_red.glb` — red-team variant.
- `preview.png` — Workbench beauty render.

Each GLB has one skin and three actions:

| Action | Frames @ 24 fps | Duration | Loop |
|--------|-----------------|----------|------|
| idle   | 33              | 1.375 s  | yes  |
| walk   | 17              | 0.708 s  | yes  |
| attack | 11              | 0.458 s  | no   |

The native raylib client loads one model instance per unit and animates each
independently. Team color comes from the exported cloth material, not a tint.
